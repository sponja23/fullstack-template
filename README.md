# Acme

A template for full-stack TypeScript web applications: a pnpm monorepo with a tRPC API over Postgres, a React single-page app, shared UI primitives, a Storybook catalog, integration tests against real databases, and continuous integration. It ships with a small invoicing product so every convention is exercised by working code rather than described in prose.

## What is inside

| Directory                               | What it is                                                                                                               |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `apps/api`                              | The HTTP server: Hono hosting tRPC, a versioned REST API, and Better Auth. Builds into a Docker image.                   |
| `apps/website`                          | The single-page app: React 19, TanStack Router, Query, and Form, Tailwind.                                               |
| `packages/backend`                      | The domain core: Drizzle schema, repositories, services, tRPC routers, and the integration-test harness. Transport-free. |
| `packages/rest-api`                     | The `/v1` REST adapter, with OpenAPI docs and API-key scopes.                                                            |
| `packages/client`                       | Browser-safe tRPC clients.                                                                                               |
| `packages/ui`                           | shadcn primitives generated by the CLI, plus a thin override layer.                                                      |
| `packages/logger`, `packages/telemetry` | Structured logging and OpenTelemetry tracing.                                                                            |
| `tools/storybook`                       | The catalog that renders every UI primitive and every website route without a backend.                                   |

The example product is an invoicing app: an organization has clients, projects, and time entries, and issues invoices from them. Its vocabulary is in [CONTEXT.md](./CONTEXT.md). A new project deletes it and builds its own domain in its place.

## Running it

Requires Node.js 22, pnpm, and Docker.

```bash
pnpm install
cp .env.example .env
pnpm db:up        # Postgres in Docker, migrated
pnpm dev          # website on :5173, API on :3000
```

Other entry points:

```bash
pnpm ready          # format, lint, type-check, build everything; run before pushing
pnpm dev:storybook  # the catalog on :5175
pnpm telemetry:up   # Grafana, Loki, Tempo on :3001, receiving traces from the API
pnpm db:studio      # Drizzle Studio
```

Tests run per package with `vp test`. The backend suites start a disposable Postgres container per run and clone a fresh database per suite.
